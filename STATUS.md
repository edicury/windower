5. **Version-mismatch handling** — built a real (not fake-fixture) older daemon in an isolated git worktree with `DAEMON_PROTOCOL_VERSION` set to 0, driven via `WINDOWER_DAEMON_BIN_PATH`. Idle case: client auto-restarted it once to a matching-version daemon and the command succeeded. Busy case: with a live recording session on the mismatched daemon, the client refused with `DAEMON_BUSY` naming the exact session id, per contract — never a silent restart, never a loop.
6. **Blocking `operate` end-to-end + mid-run Ctrl-C** — `SIGINT` mid-run produced `state: "aborted"` (`OPERATOR_ABORTED`) for the operator run itself, but the underlying recording session correctly landed `finalized` (not canceled), with a valid decodable video and manifest.
